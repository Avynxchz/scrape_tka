Kak, gimana cari titik puncak f(x) = x² − 4x + 3?
Oke, caranya singkat. Titik puncak selalu ada di x = −b/2a. Dengan a = 1 dan b = −4, kamu dapat x = 2. Substitusi ke f(x) dan hasilnya −1.
x = −b/2a
x = −(−4)/2·1 = 2
f(2) = −1
Titik puncaknya (2, −1)

4. Titik puncak dari f(x) = x² − 4x + 3 adalah …

A. (2, 3)
B. (−2, 1)
C. (2, −1) ✓
D. (1, −2)
Sebelumnya Ragu-ragu Selanjutnya

Pembahasan · Soal 4

Benar

Cari titik puncak f(x) = x² − 4x + 3, langkah demi langkah:

Langkah 1 — Identifikasi a & b

a = 1, b = −4, c = 3 dari bentuk ax² + bx + c.

Langkah 2 — Rumus x puncak

x = −b/2a = −(−4)/2·1 = 2.

Langkah 3 — Substitusi

f(2) = 4 − 8 + 3 = −1.

Langkah 4 — Tulis titik

Titik puncak (2, −1) — parabola terbuka ke atas.

Langkah 5 — Cek ulang

Cocok dengan kunci resmi. Jawaban: C.
