SOAL 8

Fungsi f : R → R dan g : R → R. Jika g(x) = x − 1 dan (f ∘ g)(x) = x³ − 4x, nilai dari f(2) = ….

A. 9
B. 13
C. 15
D. 17
E. 25
‹ Sebelumnya⚑ Ragu-raguSelanjutnya ›
Pembahasan · Soal 8✓ Kunci: C

Dari (f ∘ g)(x) = x³ − 4x dan g(x) = x − 1, cari nilai f(2):

Langkah 1 — Substitusi variabel

(f ∘ g)(x) = f(g(x)) = f(x − 1) = x³ − 4x.

Langkah 2 — Ganti variabel

Misal y = x − 1 → x = y + 1, sehingga f(y) = (y + 1)³ − 4(y + 1).

Langkah 3 — Bentuk f(x)

f(x) = (x + 1)³ − 4(x + 1).

Langkah 4 — Hitung f(2)

f(2) = (2 + 1)³ − 4(2 + 1) = 27 − 12.

Langkah 5 — Kesimpulan

f(2) = 15 → Jawaban: C. Cocok dengan kunci resmi.
